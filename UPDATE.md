Update modul PPDB yang profesional untuk Website SMKN 11 Kabupaten Tangerang. 



## Alur Pendaftar



### 1. Halaman PPDB

Berisi:

- Informasi PPDB

- Jadwal

- Persyaratan

- Alur Pendaftaran

- Kuota tiap jurusan

- FAQ

- Tombol Daftar



### 2. Registrasi

Calon siswa membuat akun menggunakan:

- Nama

- Email

- Nomor HP

- Password



### 3. Dashboard Pendaftar

Menampilkan progress pendaftaran:

- Lengkapi Biodata

- Upload Dokumen

- Submit Pendaftaran

- Menunggu Verifikasi

- Hasil Seleksi



Tampilkan juga:

- Nomor Pendaftaran

- Status

- Tanggal Daftar

- Jurusan yang dipilih



### 4. Formulir Pendaftaran

Lengkapi data:

- Biodata

- Data Orang Tua

- Data Sekolah Asal

- Pilihan Jurusan



### 5. Upload Dokumen

Upload:

- Pas Foto

- Kartu Keluarga

- Akta Kelahiran

- Rapor

- Surat Keterangan Lulus

- Dokumen pendukung lainnya



Semua file dapat dipreview sebelum dikirim.



### 6. Review & Submit

Sebelum dikirim, tampilkan ringkasan seluruh data.



Setelah menekan tombol Submit:

- Status menjadi "Menunggu Verifikasi"

- Data tidak dapat diubah kecuali diminta admin.



### 7. Status Pendaftaran

Pendaftar dapat melihat perkembangan status secara real-time:



- Menunggu Verifikasi

- Sedang Diverifikasi

- Perlu Perbaikan Dokumen

- Lolos Seleksi

- Cadangan

- Tidak Lolos

- Sudah Daftar Ulang



Jika admin memberikan catatan, tampilkan pada halaman ini.

# Admin PPDB



Buat menu PPDB pada Dashboard Admin.



## Dashboard

Tampilkan statistik:

- Total Pendaftar

- Menunggu Verifikasi

- Sedang Diverifikasi

- Perlu Perbaikan

- Lolos

- Cadangan

- Tidak Lolos

- Sudah Daftar Ulang



## Data Pendaftar

Tampilkan tabel berisi:

- Nomor Pendaftaran

- Nama

- Asal Sekolah

- Jurusan

- Tanggal Daftar

- Status

- Aksi



Sediakan fitur:

- Pencarian

- Filter berdasarkan status dan jurusan

- Pagination

- Export Excel dan PDF



## Detail Pendaftar

Admin dapat melihat:

- Biodata lengkap

- Data orang tua

- Data sekolah

- Semua dokumen yang diupload

- Riwayat status



## Verifikasi Dokumen

Admin dapat:

- Melihat dokumen

- Memberikan checklist dokumen

- Memberikan catatan

- Meminta upload ulang jika ada dokumen yang kurang atau tidak jelas



## Verifikasi Pendaftaran

Admin dapat mengubah status menjadi:

- Sedang Diverifikasi

- Perlu Perbaikan Dokumen

- Lolos Seleksi

- Cadangan

- Tidak Lolos

- Sudah Daftar Ulang



Setiap perubahan status dapat disertai catatan yang akan langsung terlihat oleh pendaftar.



## Riwayat Aktivitas

Simpan seluruh aktivitas admin seperti:

- Verifikasi dokumen

- Perubahan status

- Penambahan catatan

- Daftar ulang



---



## Ketentuan



- Gunakan tampilan modern, bersih, dan responsif.

- Gunakan badge warna untuk setiap status.

- Tambahkan loading, validasi form, modal konfirmasi, toast notification, dan empty state.

- Buat alur mudah dipahami baik oleh admin maupun calon siswa.
